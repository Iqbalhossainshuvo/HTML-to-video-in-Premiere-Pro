Edit every object in Premiere Pro or After Effects

The HTML to Video plugin (in this same project) converts the same HTML file into an editable sequence or composition: every text, image and icon on its own track/layer, movement as real keyframes.

  1. Install the plugin: run scripts/install-win.bat (Windows) or scripts/install-mac.sh (macOS) from the project folder.
  2. Restart Premiere Pro or After Effects and open Window → Extensions → HTML to Video.
  3. Click Upload your file, choose this HTML file, then Convert video.
