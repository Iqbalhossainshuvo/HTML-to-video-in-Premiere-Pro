# হিসাব খাতা (Hisab Khata)

টাকা পাঠানোর (রেমিট্যান্স) ব্যবসার দৈনিক হিসাবের মোবাইল অ্যাপ। এটি React Native (Expo) দিয়ে বানানো, তাই একই কোড Android ও iPhone দুটোতেই চলে।

- **Google দিয়ে লগইন।** সব হিসাব আপনার নিজের Google Drive-এর গোপন অ্যাপ-ফোল্ডারে (appDataFolder) জমা থাকে।
  ফোন হারালে নতুন ফোনে একই Google দিয়ে ঢুকলেই সব হিসাব ফিরে আসবে।
- **অফলাইনেও চলে।** হিসাব আগে ফোনে সেভ হয়, তারপর ইন্টারনেট পেলে Google-এ ওঠে। দুই দিকের হিসাব মিলিয়ে (merge) রাখা হয়, কিছু হারায় না।
- **নির্ভুল হিসাব।** সব টাকা পয়সা-পর্যন্ত পূর্ণসংখ্যায় (integer) রাখা হয়, তাই 0.1 + 0.2 = 0.30 ঠিকঠাক আসে।
  রেট দিয়ে রূপান্তর আর ভাগ BigInt দিয়ে করা হয়, আর রাউন্ডিং একই নিয়মে হয়। এগুলোর জন্য টেস্ট আছে (`npm test`)।
- iPhone-এর মতো পরিষ্কার ডিজাইন, লাইট/ডার্ক মোড আর বাংলা সংখ্যার অপশন আছে।

টাকার যেকোনো ঘরে সরাসরি অঙ্ক লেখা যায়, যেমন `1200+350` লিখলে নিচে `= 1,550` দেখাবে।

### লেনদেনের ধরন ও হিসাবের নিয়ম

| ধরন | হাতের ক্যাশ | যার সাথে লেনদেন তার খাতা |
|---|---|---|
| **টাকা পাঠানো** (কাস্টমার → দেশে) | + যা এখন দিল | কাস্টমার: + (টাকা + চার্জ − এখন দিল) · এজেন্ট: − দেশে পাঠানো টাকা (আমি এজেন্টকে দেব) |
| **পেলাম / জমা** (বাকি আদায়, পার্টনার দিল) | + টাকা | − টাকা |
| **দিলাম** (এজেন্টকে পরিশোধ, পার্টনারকে দিলাম) | − টাকা | + টাকা |
| **খরচ** | − টাকা | — |
| **ক্যাশ যোগ / উত্তোলন** | ± টাকা | — |
| **আগের জের** | নাম না দিলে হাতের ক্যাশ | নাম দিলে তার পুরনো বাকি/দেনা |

- খাতায় **প্লাস = সে আমাকে দেবে (পাবো)** আর **মাইনাস = আমি তাকে দেব (দেবো)**।
- এজেন্টের খাতা দেশের মুদ্রায় (যেমন BDT) রাখা হয়, বাকি সব এখানের মুদ্রায় (যেমন SAR)।
- **মোট ব্যালেন্স** = হাতে ক্যাশ + পাবো − দেবো − এজেন্টের দেনা। এজেন্টের দেনা সাধারণ রেটে রূপান্তর করে ধরা হয়, তাই তখন “(প্রায়)” লেখা থাকে।
- **আগের জের** = দিনের শুরুতে হাতে কত ক্যাশ ছিল, আর **শেষ ক্যাশ** = আগের জের + এসেছে − গিয়েছে।

## Google লগইন সেটআপ (একবারই করতে হবে)

Google লগইন চালু করতে Google Cloud-এ একটি ফ্রি OAuth client বানাতে হবে:

1. <https://console.cloud.google.com> → নতুন Project খুলুন।
2. **APIs & Services → Library**-তে গিয়ে **Google Drive API** Enable করুন।
3. **OAuth consent screen**-এ User type **External** বেছে নিন, তারপর অ্যাপের নাম আর আপনার ইমেইল দিন।
   Scope হিসেবে `.../auth/drive.appdata` যোগ করুন। *Test users*-এ যে Gmail দিয়ে ঢুকবেন সেটা যোগ করুন, অথবা অ্যাপটি **Publish** করুন।
4. **Credentials → Create credentials → OAuth client ID**:
   - **Android**: Package name `com.iqbalhossain.hisabkhata`, আর SHA-1 দিন।
     SHA-1 পাবেন GitHub Actions-এর “Build Hisab Khata” কাজের লগে, “Signing certificate” ধাপে।
   - **Web application**: একটা বানান এবং এর Client ID কপি করুন।
5. GitHub repo → **Settings → Secrets and variables → Actions**-এ `GOOGLE_WEB_CLIENT_ID` নামে Web Client ID রাখুন।
6. Actions থেকে আবার বিল্ড চালান, তারপর **HisabKhata-android** artifact থেকে APK নামিয়ে ফোনে ইনস্টল করুন।

> সেটআপ শেষ হওয়ার আগে লগইন স্ক্রিনের **“Google ছাড়া চালু করুন”** দিয়ে অ্যাপ ব্যবহার করা যায়।
> পরে প্রোফাইল থেকে Google যুক্ত করলে ফোনের সব হিসাব Google-এ উঠে যাবে।

**iPhone:** Google Cloud-এ একটি **iOS** OAuth client বানান (Bundle ID `com.iqbalhossain.hisabkhata`)।
তারপর `GOOGLE_IOS_CLIENT_ID` দিয়ে EAS-এ বিল্ড করুন: `GOOGLE_IOS_CLIENT_ID=... npx eas-cli@latest build -p ios`।

## ডেভেলপারদের জন্য

```bash
cd hisab-app
npm ci
npm test            # হিসাবের টেস্ট (calculator, রেট, ব্যালেন্স, দৈনিক রিপোর্ট, merge)
npx tsc --noEmit    # typecheck
npx expo lint
npx expo run:android   # ডিভাইস/এমুলেটরে চালাতে (Expo Go-তে Google লগইন চলবে না)
```

কোড কোথায়:

- `src/core/` – হিসাবের সব লজিক (UI ছাড়া, টেস্ট করা):
  - `money.ts` – পয়সা আর রেট
  - `calc.ts` – ক্যালকুলেটর
  - `ledger.ts` – ব্যালেন্স আর রিপোর্ট
  - `merge.ts` – ফোন আর Google-এর হিসাব মেলানো
- `src/data/` – ফোনে সেভ (`storage.ts`), Google লগইন ও Drive (`google.ts`), অ্যাপের স্টেট ও সিঙ্ক (`store.tsx`), CSV (`export.ts`)
- `src/app/` – স্ক্রিনগুলো (Expo Router)
- `src/ui/` – ডিজাইন: থিম আর কম্পোনেন্ট
